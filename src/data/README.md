# Data Layer – демонстрационные данные

- `mock/` – условный демо-объект и детерминированные генераторы рядов (seed → одинаковые данные).
- `scenarios/` – каталог `TestScenario`: входные данные + ожидаемый исход проверок по этапам.
  Используются и в UI (выбор сценария), и в интеграционных тестах движка.

Реквизиты демо-объекта условные. Реальные значения берутся из паспорта кейса OE-04.
