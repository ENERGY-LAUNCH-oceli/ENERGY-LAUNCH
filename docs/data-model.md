# Модель данных

Доменные типы – `src/types`, схемы входа – `src/schemas` и Zod-схемы в импортёрах. Перечисления объявлены
`const`-массивами (`STAGE_IDS`, `STAGE_STATUSES`, …): из них выводятся и типы TS, и `z.enum`.

## Сущности

| Сущность | Назначение |
| --- | --- |
| `EnergyObject`, `ObjectPassport`, `GridConnection` | Объект, его паспорт и точка подключения (EAN offtake / injection) |
| `SitePassport` | Разобранный `object.json`: активы, сигналы, `data_files`, `csv_format`, timezone |
| `InvoiceDataset`, `TelemetryDataset` | Версии загруженных наборов; хранится отчёт анализатора, а не строки |
| `ControlCommand` | Тест управления: command_id, asset_id, значение, Sent / Received / Responded, трасса, итог, seed |
| `DashboardWorkspace` | Черновик, опубликованные версии и приёмки панели объекта |
| `LaunchSession` | Этапы со статусами, результаты проверок, препятствия, материалы, подтверждения |
| `ValidationSnapshot`, `InputRef`, `StaleMark` | След: прогон проверок, неизменяемая ссылка на версию входа, устаревание |
| `AuditEvent` | Запись журнала: событие, время, автор, объект, этап, данные |

## Соглашения

| Что | Как |
| --- | --- |
| Время | ISO 8601, хранится в UTC (`2026-11-05T10:00:00.000Z`). Метка без зоны – нарушение (MH-006 / TM-009) |
| Часовой пояс объекта | `Europe/Brussels` из паспорта; используется для границ месяцев и окна истории (переходы на летнее время учитываются) |
| Шаг | 15 минут; ряды другой частоты хранятся как есть и не досоздаются |
| Единицы | Из имени колонки: `power_kW` – кВт, `energy_kWh` – кВт·ч за интервал, `SOC_%` – % |
| Знаки | Энергия ≥ 0; `Grid.power_kW` > 0 – потребление, < 0 – выдача; `CA_injection` ≤ 0; PV ≥ 0 |
| EAN | 18 цифр, контрольная цифра GS1; offtake и injection различны |
| object_id | Из `object.json`; все наборы, команды, панели и приёмки объекта несут его и сверяются |
| asset_id | Из паспорта (`pv-1`, `battery-1`); префикс сигналов – `PV1`, `Battery1`; без номера – единственный актив; `total` – сумма |
| Идентификаторы версий | `invoice-<object>-v<N>`, `telemetry-<object>-v<N>`; прошлые версии не удаляются |

## Хранение

IndexedDB (Dexie, база `VITE_DB_NAME`): рабочие пространства объектов и журнал аудита. Набор кейса не
копируется в базу – он читается из `public/case4` при каждом старте и сверяется по SHA-256 из `manifest.json`.
