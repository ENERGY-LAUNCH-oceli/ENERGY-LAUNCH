# Обучение, FAQ и помощник по сайту

Раздел `/help` («Обучение» в боковой панели) устроен по образцу обучения пресс-центра ak.xroyse.ru/press
(`Project/AK/js/press-tour.js`, `press-help.js`), но урок и тур – отдельные для каждого блока сайта.

## Уроки и туры

| Файл | Что внутри |
| --- | --- |
| `src/features/help/lessons.tsx` | 12 уроков: текст, таблицы, подсказки, ссылка «Где это» |
| `src/features/tour/tours.ts` | Тур с тем же id на каждый урок: шаги, переходы, действия «за пользователя» |
| `src/features/tour/TourHost.tsx` | Затемнение с «окном» вокруг элемента, карточка шага, клавиатура |
| `src/features/tour/demo.ts` | Ожидание элемента, нажатие, печать в поле (React получает обычные события) |

Уроки: новый объект, загрузка файлов перетаскиванием, обзор, карточка запуска, этапы 1–4, препятствия, журнал и протокол, сценарии, настройки.
Кнопка **«Показать на сайте»** запускает тур: он открывает нужную страницу, подсвечивает элементы и сам выполняет
действия – например, открывает форму «Новый объект», печатает название (код подставляется сам), вводит 17 цифр EAN и
нажимает «Подставить контрольную цифру». В туре ничего не сохраняется: форма закрывается в конце.

Как в пресс-центре: тур модальный (подложка перехватывает клики), ← → листают шаги, Esc закрывает, фокус остаётся в
карточке; нет элемента на экране – карточка по центру. Окна приложения (`components/ui/dialog.tsx`) не закрываются от
щелчков по карточке тура. Пройденные уроки помнит браузер (`localStorage: el.help.done`).

Якоря для туров – атрибуты `data-tour` и существующие `data-testid`/`id` (`config/blocker-links.ts`). Переименовали
блок – поправьте селектор в `tours.ts`; проверка всех туров – e2e и сценарий из раздела «Проверка» ниже.

## Боковая панель и контекстное меню

Внизу боковой панели (и в меню на телефоне) всегда виден блок «Помощь» (`components/layout/SidebarHelp.tsx`):
**«Как это работает»** – тур по текущей странице, **«Задать вопрос»** – окно помощника. В свёрнутой панели – значки
с подсказками. Те же действия – в меню правой кнопки мыши:


- **«Обучение: как работает эта страница»** – тур по текущему разделу (`tourForPath`).
- **«Помощь: задать вопрос…»** – окно с вопросом помощнику; выделенный текст подставляется в вопрос.

## FAQ и помощник по сайту

База знаний – `src/help/knowledge.ts` (44 вопроса, темы, ключевые слова, связанный урок). Её используют и страница
FAQ, и помощник.

Помощник (`src/help/agent.ts`) живёт на сервере (`POST /api/help/ask`) и **не обращается к внешним ИИ-сервисам**:
нормализация текста, упрощённая основа слова, синонимы, исправление опечаток (триграммы) и ранжирование BM25 по
вопросу, ключевым словам и ответу. Уверенность ниже порога – честное «пока не знаю», без выдуманного ответа.
Текст вопроса – только данные для поиска: помощник не выполняет действий и не меняет статусы.

Вопросы сохраняются в таблице `help_questions` (одинаковые по смыслу формулировки – одна строка со счётчиком).
В разделе FAQ «Вопросы пользователей» показываются только вопросы с найденным ответом и без ссылок, почты и
телефонов. Без сервера ответ подбирается тем же кодом в браузере, вопрос не сохраняется.

| Метод | Путь | Назначение |
| --- | --- | --- |
| POST | `/api/help/ask` | `{ question }` (3–300 знаков) → ответ, похожие вопросы, `saved`, `published` |
| GET | `/api/help/questions` | Опубликованные вопросы пользователей (последние 50) |

Новый частый вопрос: добавьте запись в `knowledge.ts` (вопрос, ответ, ключевые слова, урок) и пример формулировки в
`tests/unit/help-agent.test.ts`. Неотвеченные вопросы видны в базе: `select text, count from help_questions where faq_id is null`.

## Проверка

- `tests/unit/help-agent.test.ts` – формулировки своими словами, опечатки, посторонние вопросы, инструкции во входе.
- `tests/server/api.test.ts` – API помощника: сохранение, счётчик, публикация, личные данные.
- `tests/e2e/smoke.spec.ts` – тур «Новый объект» (форма заполняется, объект не создаётся), клавиатура тура,
  помощь из контекстного меню, поиск по FAQ.
